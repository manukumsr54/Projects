# 🧠 Decision Making Website

A simple and interactive web application that helps users make decisions when they are confused between multiple choices. Users can enter different options, and the website randomly selects one, making decision-making quick and easy.

---

## 📌 Features

- ➕ Add multiple decision options
- ❌ Remove individual options
- 🗑️ Clear all options
- 🎲 Randomly pick one option
- 📱 Responsive and user-friendly interface
- ⚡ Instant results without page reload

## 🚀 Getting Started

Run the Website

Open `index.html` in any modern web browser.

No installation or additional dependencies are required.

---

## 💡 How It Works

1. Enter your choices in the input field.
2. Click **Add Option** to save each choice.
3. Repeat until all options are added.
4. Click **Decide** or **Pick Random**.
5. The website randomly selects one option and displays the result.
